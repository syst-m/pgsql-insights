# License manifest (R15.1, R15.3)

The project license is **Apache-2.0** — the full text is [`LICENSE`](../../LICENSE) at
the repo root, and `chart/Chart.yaml` advertises it to Artifact Hub via
`artifacthub.io/license: Apache-2.0`.

This directory holds the *dependency* side of R15.1:

| File | Generated by | Content |
|---|---|---|
| `go-dependencies.txt` | `make licenses` | every module in the module graph (`go list -m all`) |

Phase 0 has zero external Go dependencies (R13.10 keeps the module graph empty until
Phase 1 pulls in a Kubernetes client), so the manifest lists the module itself and
nothing else. That is the point of generating it now: the file exists, CI regenerates
it, and the first real dependency cannot land without showing up in a diff.

## What changes in Phase 9

R15.3 asks for per-dependency license *text*, not just a module list. Once the module
graph is non-empty, `make licenses` grows a second step that runs
`go-licenses report ./...` and writes one file per dependency, plus the notices for the
vendored SPA assets (R15.4). Until then the header in `go-dependencies.txt` says so
explicitly rather than pretending the file is complete.

## Images

The distroless base image is Apache-2.0 and carries its own license text inside the
image (R15.5). The pinned digests live in the `Dockerfile`; Renovate keeps them current
(`.github/renovate.json`).
