# Implementation status — pgsql-insights

The phase-by-phase record of what has been built, by whom, and what proves it.
`IMPLEMENTATION.md` at the repo root is the shell; this directory is the detail.

**How to read it.** Every phase file carries the same sections — Status, Owners, Task breakdown,
Validation entry (R14.2), Requirement → file → status (R14.8). The tables are copied byte for byte
from the root file, so a `path:N` citation resolves from either copy. Prose is short by design: a
status table states status, and the history behind a status lives in git and in
[deviations.md](deviations.md), not in the cell.

Status legend: ⬜ not started · 🔄 in progress · ✅ done · ⚠️ done with deviations
